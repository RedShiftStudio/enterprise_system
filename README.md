# AI-Powered CRM & Lead Intelligence System

Комплексный микросервисный модуль / бэкенд CRM-системы со встроенным AI-движком скоринга лидов, анализа тональности коммуникаций и рекомендаций сделок.

---

## 🚀 Архитектура проекта

```text
ai_crm_core/
├── app/
│   ├── __init__.py
│   ├── main.py              # Точка входа FastAPI приложения и роутинг
│   ├── config.py            # Настройки окружения и параметры AI-моделей
│   ├── database.py          # Инициализация SQLAlchemy и подключение к БД

│   │   ├── __init__.py
│   │   ├── customer.py      # Модели клиентов, контактов и лидов
│   │   └── deal.py          # Модели сделок, стадий воронок и логов взаимодействий
│   ├── schemas/
│   │   ├── __init__.py
│   │   ├── customer.py      # Pydantic схемы валидации клиентов и лидов
│   │   └── deal.py          # Pydantic схемы для воронки продаж и AI-метрик
│   └── services/
│       ├── __init__.py
```

## ⚡ Основные возможности

1. **CRM Pipeline Management**:
   - Полный цикл управления воронкой продаж (Новый -> Квалификация -> Предложение -> Переговоры -> Успешно/Отказ).
   - Учет взаимодействий (звонки, почта, встречи) и истории клиента.

2. **AI Intelligence Engine**:
   - **Lead Scoring**: Расчет вероятности закрытия сделки на основе поведенческих факторов, параметров компании, бюджета и истории контактов.
   - **Sentiment & Intent Analysis**: Определение настроения клиента и готовности к покупке по тексту заметок/писем.
   - **Next Best Action**: Автоматические рекомендации менеджеру по следующему шагу (предложить скидку, созвониться с ЛПР, выставить счет).

## 🛠 Запуск и установка

### Локально:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```
Сервис будет доступен по адресу: `http://localhost:8000` (Swagger UI: `http://localhost:8000/docs`).

### Через Docker:
```bash
docker-compose up --build
```
